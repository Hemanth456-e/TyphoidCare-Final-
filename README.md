# Heart Disease FL React GUI

Frontend-only React/Vite implementation styled like the supplied healthcare dashboard reference.

Includes:
- Login with Admin / Hospital / User role selection
- Admin dashboard
- Individual hospital pages
- Hospital/client dashboard
- Patient prediction interface
- FL workflow, metrics, cards, tables and responsive navigation
- Editable React/JSX/CSS, not screenshots

No backend, database, API, real authentication, or real ML model is connected.

Render:
Build Command: npm install && npm run build
Publish Directory: dist

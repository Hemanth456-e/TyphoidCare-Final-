# Heart Disease Federated Learning — All Individual Pages in One Site

This combines the four individual React projects previously created:
1. Login
2. Admin Dashboard
3. Hospital Dashboard
4. User/Patient Dashboard

The original page source and original styling are kept separately under `src/pages/`.
The only new routing layer is `src/App.jsx`.

Login role selection:
- Admin -> Admin page
- Hospital -> Hospital page
- User -> User page

## Render
Root Directory: leave empty
Build Command: npm install && npm run build
Publish Directory: dist

Frontend-only demo. No backend/database/real ML connection.
